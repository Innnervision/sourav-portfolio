# sourav-portfolio

Production-ready personal portfolio for Sourav Mukherjee.

## Subdomain
https://resume.universeinvedors.tech

## Tech Stack
- Next.js 15.3.9 with App Router
- TypeScript
- Tailwind CSS
- Framer Motion

## Build
```bash
npm install
npm run build
```

## Assets needed
- `public/images/SouravMukherjeeCEO.png` — Profile photo
- `public/resume.pdf` — Resume PDF for download

## Deployment
The `out/` directory contains the static export ready for deployment.
